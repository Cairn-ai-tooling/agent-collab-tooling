# Roadmap

The single view of **what's outstanding**. Items are grouped **Now / Next / Later** by intent, not
deadline. Each row has a stable id (e.g. `X1`) so a graduated backlog artifact can point back at it
(`--roadmap-ref X1`, see [`docs/product/README.md`](product/README.md)). When work on a row starts,
graduate it into an Epic with the `/product-item` skill and add the `→ EPIC-NNN` pointer to its row.
